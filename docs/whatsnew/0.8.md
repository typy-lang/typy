# What's new in TyPy 0.8

TyPy 0.8.0 was released on 2026-11-19. This page summarises what it
changes for you as you write programs; the
[changelog](changelog.md#080-2026-11-19) lists every change, with the
requirement and the decision record of each.

## Summary

- Functions, methods, nested functions and `lambda` expressions are
  values of type `Callable[[A, ...], R]`, which you store, pass, return
  and call as in CPython.
- A nested function reads the variables of the functions around it, and
  assigns them after `nonlocal`, with CPython's meaning, loop variables
  included.
- `sorted`, `list.sort`, `min` and `max` take a `key`.
- Functions take positional-only parameters, before `/`, and keyword-only
  parameters, after `*`.
- Objects with `bool` or `float` fields beside others take less memory.

## Functions as values

A function's name read without a call is its function object. A
`Callable` annotation from `typing` or `collections.abc` names its type,
and a call through it passes each argument by position (FUN-05):

<!-- typy-expect: accepted -->
```python
from typing import Callable


def double(value: int) -> int:
    return value * 2


class Counter:
    def __init__(self) -> None:
        self.count = 0

    def add(self, step: int) -> int:
        self.count += step
        return self.count


def apply(function: Callable[[int], int], value: int) -> int:
    return function(value)


counter = Counter()
add = counter.add
print(apply(double, 4), apply(add, 3), apply(add, 2), counter.count)
```

A method read through an instance is a bound method that holds the
instance, and `item.name(...)` for a property calls the function its
getter gives. A function fits a `Callable` only when a call through it
converts nothing, so a function of a `float` does not fit a
`Callable[[int], float]` (NFR-19).

## Nested functions and closures

A `def` inside a function makes a new function object each time it runs.
It reads the variables of the functions around it: a variable given its
value once before the `def` is copied, and any other lives in a cell the
functions share, so functions made in a loop read the last value of its
variable, as in CPython. After `nonlocal`, a nested function assigns the
variable (FUN-04, SMT-09):

<!-- typy-expect: accepted -->
```python
from typing import Callable


def make_counter() -> Callable[[], int]:
    count = 0

    def increment() -> int:
        nonlocal count
        count += 1
        return count
    return increment


def parity(n: int) -> str:
    def even(k: int) -> bool:
        return True if k == 0 else odd(k - 1)

    def odd(k: int) -> bool:
        return False if k == 0 else even(k - 1)
    return "even" if even(n) else "odd"


counter = make_counter()
counter()
print(counter(), parity(7))
```

Nested functions that call one another by name, defined one after
another, hold the same captures and never each other, so they are freed
with their last reference. No test narrows a variable that a nested
function assigns, since any call may assign it.

## Lambda expressions and keys

A `lambda` takes its parameter types from the `Callable` its context
expects, and its result type from it or from its body. The `key` of
`sorted`, `list.sort`, `min` and `max` passes each item (EXP-14, FUN-05):

<!-- typy-expect: accepted -->
```python
from typing import Callable

scale: Callable[[int], int] = lambda x: x * 3
words = ["pear", "fig", "banana"]
shortest = min(words, key=lambda word: len(word))
print(scale(5), sorted(words, key=lambda word: (len(word), word)))
print(shortest, max(words, key=lambda word: word[-1]))
```

## Positional-only and keyword-only parameters

A parameter before `/` is passed by position only, and one after `*` by
keyword only, and a call binds its arguments as CPython does (FUN-03):

<!-- typy-expect: accepted -->
```python
def clamp(value: int, /, *, low: int = 0, high: int = 10) -> int:
    return max(low, min(high, value))


print(clamp(15), clamp(-3, low=-5), clamp(4, high=3))
```

## Smaller objects

An instance and a tuple store their attributes and items by decreasing
alignment, so a `bool` beside `int`s no longer takes 8 bytes of its own.
A class of two `int`s, a `float`, an object and two `bool`s takes 56
bytes, not 64. Your program sees its declared order everywhere: in
`repr`, comparisons, hashing, `match` and dataclass fields (MEM-11).

## Other changes

- An operand read from an object, a container or a module variable stays
  alive while a later operand runs, so `current.text + replace()`, where
  `replace` binds `current` again, adds the old text, as CPython does,
  where TyPy 0.7 read freed memory.
- Calling a value that is not a function, such as an `int`, is E0401, as
  CPython raises `TypeError`.
- `except ... as name` where a function declares `name` `global` is
  E0202, since CPython deletes the module variable when the clause ends.
