# What's new in TyPy 0.12

TyPy 0.12.0 was released on 2026-11-24. This page summarises what it
changes for you as you write programs; the
[changelog](changelog.md#0120-2026-11-24) lists every change, with the
requirement and the decision record of each.

## Summary

- A function's result, and an empty `[]`, `{}` or `set()`, take their
  types from the code that uses them.
- `typing.Literal`, `@overload`, `Self`, `TypeGuard` and `TypeIs`.
- `enum` classes and abstract classes of `abc`.
- The standard library modules `bisect`, `heapq`, `string`, `textwrap`,
  `base64` and `binascii`, written in typed Python with CPython 3.15's
  results.
- The builtins `hash`, `divmod`, `pow`, `bin`, `hex`, `oct`, `format` and
  `bytearray`.
- From the Python floor 3.15: `frozendict`, `math.integer` and unpacking
  in comprehensions.
- Code that cannot run is neither checked nor compiled.
- A richer command line: optimisation levels, a target processor,
  `typy print`, `typy run -c` and `-m`, per-code warning levels, colour
  and timings.
- The benchmark suite runs within 4.06 times the time of its C
  programs.

## Results and empty collections inferred

A module-level function or an instance method may leave out its result
annotation: its result is the type its `return` statements give (TYP-26).
An empty `[]`, `{}`, `set()`, `dict()` or `list()` assigned to a variable
takes the type of the first item the function adds to it (TYP-27):

<!-- typy-expect: accepted -->
```python
def area(width: int, height: int):
    return width * height


def squares(count: int) -> list[int]:
    found = []
    for number in range(count):
        found.append(number * number)
    return found


print(area(3, 4) + 1, squares(4))
```

Parameters keep their annotations. A static, class or special method, a
property, a method that overrides or is overridden, a method of a generic
class or a protocol, a generator, a function that calls itself and a
function a library exports keep their result annotation, and a nested
function's result is inferred from 0.13 (TYP-33).

## Literal types, overloads and `Self`

`Literal[...]` of `int`, `str`, `bytes` and `bool` constants and of
`None` takes only its values, and a test against them narrows a variable
(TYP-28). `@overload` gives a module function or an instance method more
than one signature (TYP-29), and `Self` in a method is the class it is
called through (TYP-30):

<!-- typy-expect: accepted -->
```python
from typing import Literal, Self, overload

type Mode = Literal["r", "w"]


def describe(mode: Mode) -> str:
    return "read" if mode == "r" else "write"


@overload
def double(value: int) -> int: ...
@overload
def double(value: str) -> str: ...
def double(value: int | str) -> int | str:
    return value * 2


class Counter:
    def __init__(self) -> None:
        self.count = 0

    def add(self, step: int) -> Self:
        self.count += step
        return self


print(describe("w"), double(21), double("ab"), Counter().add(2).add(3).count)
```

A function whose result is `TypeGuard[T]` or `TypeIs[T]` narrows its
argument where a test of its call is true, and `TypeIs` also where it is
false (TYP-31). `TypeIs` needs the Python floor 3.13. The rest of
`@overload` and `Self`, such as overloads of special methods, is planned
for 0.13 (TYP-35, TYP-36).

## Enum and abstract classes

A class derived from `Enum`, `IntEnum`, `StrEnum`, `Flag` or `IntFlag`
has its members as instances, with `name`, `value`, `auto()`, lookup by
value and by name, iteration and `len` (CLS-44). A class derived from
`abc.ABC` with an `@abstractmethod` cannot be made until a derived class
defines the method (CLS-45):

<!-- typy-expect: accepted -->
```python
from abc import ABC, abstractmethod
from enum import Enum, IntFlag, auto


class Color(Enum):
    RED = auto()
    GREEN = auto()


class Access(IntFlag):
    READ = 1
    WRITE = 2


class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...


class Square(Shape):
    def __init__(self, side: float) -> None:
        self.side = side

    def area(self) -> float:
        return self.side * self.side


print(Color.GREEN, Color(1).name, len(Color), Access.READ | Access.WRITE)
print(Square(2.0).area())
```

An enum class with other bases or decorators, a member annotated or
assigned a tuple, a value other than a constant or `auto()`, and an enum
class defining `__init__` or `_missing_` are planned for 0.13 (CLS-47).

## Standard library modules in typed Python

`bisect`, `heapq`, `string`, `textwrap`, `base64` and `binascii` are
written in typed Python that CPython also runs, and give CPython 3.15's
results and messages (LIB-27). A test compares their signatures with
typeshed's:

<!-- typy-expect: accepted -->
```python
import bisect
import heapq
import textwrap
from base64 import b64encode
from string import Template

scores = [10, 20, 30]
bisect.insort(scores, 25)
print(scores, heapq.nsmallest(2, [5, 1, 4]), b64encode(b"TyPy"))
print(textwrap.shorten("TyPy compiles typed Python ahead of time", 24))
print(Template("$name is typed").substitute(name="TyPy"))
```

`key` arguments, the functions and parameters Python 3.13 to 3.15 add,
`copy`, `statistics`, `time` and `random` are planned for 0.13 (TYP-35,
LIB-32, LIB-33, LIB-30).

## Hashes and number builtins

`hash(x)` gives the hash a set or a dict keeps `x` by: CPython's for
numbers, `None` and tuples of them, and what `__hash__` returns for an
instance (LIB-34). `divmod`, `pow` with a modulus, `bin`, `hex`, `oct`,
`format` and `bytearray`, a `bytes` that changes in place, are there as
CPython gives them (LIB-28):

<!-- typy-expect: accepted -->
```python
class Point:
    def __init__(self, x: int, y: int) -> None:
        self.x = x
        self.y = y

    def __eq__(self, other: "Point") -> bool:
        return (self.x, self.y) == (other.x, other.y)

    def __hash__(self) -> int:
        return hash((self.x, self.y))


data = bytearray(b"typy")
data[0] = ord("T")
print(len({Point(1, 2), Point(1, 2)}), data, divmod(17, 5), pow(3, 4, 5))
print(hex(255), format(3.14159, ".2f"))
```

## Python 3.15

From the Python floor 3.15, set with `python-floor = "3.15"` in
`typy.toml`:

- `frozendict`, an immutable mapping made from what `dict` takes, with
  CPython's text and hash, read as a dict by `dict()`, `**`, `update` and
  `|` (DAT-18).
- `math.integer`, with `comb`, `factorial`, `gcd`, `isqrt`, `lcm` and
  `perm` (LIB-26).
- A comprehension element that unpacks, as in `[*row for row in rows]`
  and `{**table for table in tables}` (EXP-23).

## Code that cannot run

A statement after `return`, `raise`, `break` or `continue`, and a branch
that a test of `True`, `False`, `isinstance`, an `assert` or a class
pattern rules out by the types, are neither checked nor compiled, so a
program with such code, which CPython runs, is accepted (TYP-34). A
pattern that never matches is the warning W0402.

## The command line

| Option | What it does |
| --- | --- |
| `-O0` to `-O3`, `-Os`, `-Oz` | Choose how much a build optimises |
| `--target-cpu NAME`, `-C KEY=VALUE` | Build for a processor, or set a code generation option |
| `typy print WHAT` | Write the targets, processors, paths or settings `typy` uses |
| `typy run -c CODE`, `typy run -m MODULE` | Run code or a module, as `python -c` and `-m` do |
| `-W CODE`, `-A CODE`, `-D CODE` | Report a warning, allow it, or deny it |
| `--color auto\|always\|never` | Colour diagnostics |
| `--timings`, `-v`, `--save-temps` | Show stage times and commands, and keep the object file |
| `--emit A,B` | Write several stages at once |
| `typy NAME ARGS` | Run `typy-NAME` from `PATH`, as `git` runs its commands |

## Speed

`int` arithmetic and comparisons on values that fit in 63 bits, list
items, and `//`, `%`, `float()` and `/` run in the generated code, and the
runtime is called only where an operation may raise or an item needs a
reference count. The benchmark suite's geometric mean is 4.06
times its C programs' time, within NFR-22's 5. Integers above 63 bits
run 1.5 to 1.8 times CPython 3.15's time up to 1024 bits.

## Migrating from 0.11

- A never-matching class, sequence or mapping pattern is the warning
  W0402 rather than the error E0407. With `--deny-warnings` it still
  stops the build.
- With `--deny-warnings`, a warning is reported as `error[W0101]`, and
  JSON output gives it `"severity":"error"`; read the `W` code to find a
  denied warning.
- `copy`, `statistics`, `time` and `random` are refused naming 0.13.
- `import` of `itertools`, `collections`, `datetime`, `pathlib`,
  `os.path`, `fractions`, `re` and `warnings` is E0201 naming 0.13, and
  of `json`, `functools`, `argparse`, `logging` and `csv` E0201 naming
  0.14, where each was E0206.
- The hash of an instance is what its `__hash__` returns when that fits
  64 bits, so a set of such instances may iterate in another order.

## Other changes

- A `bytes` default of a parameter, such as `separator: bytes = b", "`,
  is passed by a call that leaves the parameter out.
- A `lambda` in a tuple, such as `("double", lambda x: x * 2)` in a list
  of pairs, takes the `Callable` the tuple's type expects.
- A generic function compares values of its type parameters, each copy
  checking its own types (GEN-18).
- `from __future__ import annotations` is accepted (LIB-29).
