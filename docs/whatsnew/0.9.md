# What's new in TyPy 0.9

TyPy 0.9.0 was released on 2026-11-20. This page summarises what it
changes for you as you write programs; the
[changelog](changelog.md#090-2026-11-20) lists every change, with the
requirement and the decision record of each.

## Summary

- Generator functions, with `yield`, `yield from`, `send`, `throw`,
  `close` and a return value, and generator expressions.
- A generator freed while it is suspended closes and runs its `finally`
  blocks where CPython does.
- `*args` and `**kwargs` parameters, and `*` and `**` in calls, in
  displays and in assignment targets.
- A class with `__iter__` and `__next__` is an `Iterator[T]`, and one with
  `__iter__` an `Iterable[T]`.
- `isinstance` and class patterns tell a generator, an iterator and an
  iterable apart.

## Generators

A function whose body has a `yield` makes a generator when it is called.
Annotate it to return `Iterator[T]` or `Iterable[T]`, or
`Generator[Y, S, R]` to send it values and give it a result, which
`yield from` passes back (SMT-11, FUN-07, ADR-0063, ADR-0072):

<!-- typy-expect: accepted -->
```python
from collections.abc import Generator, Iterator


def countdown(start: int) -> Iterator[int]:
    while start > 0:
        yield start
        start -= 1


def running_total() -> Generator[int, int, str]:
    total = 0
    while total < 10:
        received = yield total
        if received is not None:
            total += received
    return f"done at {total}"


def report() -> Generator[int, int, None]:
    result = yield from running_total()
    print(result)


print(list(countdown(3)), sum(n * n for n in countdown(3)))
totals = report()
print(next(totals), totals.send(4), totals.send(5))
try:
    totals.send(6)
except StopIteration:
    print("finished")
```

`received = yield total` is an `int | None`, since `next()` and a `for`
loop resume a generator with `None` (ADR-0067). A generator expression,
`(n * n for n in values)`, is a `Generator[T, None, None]` whose first
iterable runs where the expression runs (EXP-15).

## Closing a generator

A generator that is freed while it is suspended closes: `GeneratorExit`
is raised at its `yield`, so its `except` clauses and `finally` blocks
run, as in CPython, here when the loop leaves it early (FUN-11,
ADR-0069):

<!-- typy-expect: accepted -->
```python
from collections.abc import Iterator


def lines() -> Iterator[str]:
    try:
        yield "first"
        yield "second"
    finally:
        print("cleaned up")


for line in lines():
    print(line)
    break
print("after the loop")
```

## Variable numbers of arguments and unpacking

`*args: T` takes the positional arguments left over as a
`tuple[T, ...]`, and `**kwargs: T` the keyword arguments as a
`dict[str, T]`. A call unpacks a list with `*` and a dict with `**`,
checked as CPython checks it when the call runs, and displays and
assignment targets unpack too (EXP-17, ADR-0073):

<!-- typy-expect: accepted -->
```python
def describe(name: str, *tags: str, **sizes: int) -> str:
    return f"{name} {tags} {sizes}"


def forward(*tags: str, **sizes: int) -> str:
    return describe("box", *tags, **sizes)


first, *rest = [1, 2, 3]
point = (3, 4)
print(forward("red", width=2), [*rest, *point], {**{"a": 1}, "b": 2})
```

## Iterator classes

A class whose `__next__` returns `T` and whose `__iter__` returns the
instance is an `Iterator[T]`, and a class whose `__iter__` returns an
iterator is an `Iterable[T]`, as `typing` reads the protocols, so you pass
its instances to any function that takes one (TYP-20, ADR-0065).
`isinstance` and class patterns tell generators, iterators and iterables
apart, and an `Iterable[T]` found an `Iterator` is read as one (TYP-21).

## Migrating from 0.8

- A class pattern that names `Iterator`, `Iterable`, `Generator`, `List`,
  `Dict`, `Set`, `Tuple`, `Type`, `Optional` or `Union` of `typing` is
  E0401, since CPython raises `TypeError` for it. Name the class of
  `collections.abc`, such as `case Iterator():` after
  `from collections.abc import Iterator`, or the built-in type, such as
  `case list():`.
- `Sequence`, `Mapping` and the other abstract collections, `NamedTuple`,
  decorators and the other forms planned for 0.9 by TyPy 0.8 are now
  planned for 0.10.

## Other changes

- A class pattern of `Iterator` over a union that holds an iterator
  matches it, and a generator passed where a union holding an
  `Iterable[T]` is expected compiles.
- A function, method or `lambda` with `*args` or `**kwargs` used as a
  value, and `*` or `**` in a call of a builtin other than `print`, of a
  function value or of an exception class, are planned for 0.10 (FUN-13,
  EXP-19).
