# What's new in TyPy 0.6

TyPy 0.6.0 was released on 2026-11-18. This page summarises what it
changes for you as you write programs; the
[changelog](changelog.md#060-2026-11-18) lists every change, with the
requirement and the decision record of each.

## Summary

- TyPy runs on 64-bit Arm (AArch64) Linux as well as x86_64 Linux, and
  builds programs for either from either.
- `ctypes` structures pass to and from C functions by value on AArch64 as
  its C calling convention passes them.
- The documentation is published at <https://typy-lang.org>, laid out in
  the sections of Python's documentation.
- Each release archive carries the licences and notices of the code it
  holds that is not TyPy's own.

## AArch64 Linux

Each release has two archives, one for x86_64 hosts and one for AArch64
hosts such as a Raspberry Pi 4 or 5 with a 64-bit system or an Arm server.
Both hold the runtime of every target; [Getting started](../tutorial/index.md)
shows how to pick the one for your machine.

`typy build --target aarch64-unknown-linux-gnu` builds an AArch64
program on an x86_64 machine, and `--target x86_64-unknown-linux-gnu` the
other way round (CLI-08). TyPy links it with the cross toolchain named
after the target, such as `aarch64-linux-gnu-gcc`, which Debian and
Ubuntu package; a table `[target."TRIPLE"]` in `typy.toml` names other
tools (CLI-14). An emulator such as `qemu-aarch64` runs the program on the
machine that built it.
[Building for another target](../using/command-line.md#building-for-another-target)
shows each step.

A program behaves alike on both: TyPy's test suite runs every accepted
conformance test built for AArch64 and compares it with CPython (NFR-16).

## C structures by value

A `ctypes.Structure` passed to or returned from a C function by value
follows AAPCS64 on AArch64: up to four `float`s or `double`s go in
floating-point registers, other structures of up to 16 bytes in general
registers, and a larger one as the address of a copy the function may
change, which leaves your object as it was (FFI-12). Nothing changes in
the program you write; see
[Calling C through ctypes](../extending/c-interop.md#calling-c-through-ctypes).

## Documentation

The documentation at <https://typy-lang.org> follows the sections of
Python's own: What's new, the tutorial, the library and language
references, setup and usage, extending and embedding, and diagnostics,
with search and light and dark modes. Its pages moved within the
repository; the [changelog](changelog.md#060-2026-11-18) gives each old
and new path.

## Licences

The release archive carries `THIRD-PARTY-NOTICES.md` for the parts of the
runtime derived from CPython and the Unicode Character Database, and a
`licenses/` directory with the licences of the Rust crates, LLVM and the
Rust standard library that `typy` and its programs contain; see
[Licence](../about/licence.md). TyPy's own licence is unchanged.
